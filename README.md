# embedded-systems-projects

Arduino and embedded systems projects.

## Structure

Each project lives in its own directory under `projects/`:

```
projects/
  project-name/
    project-name.ino   # Arduino sketch
    README.md          # Wiring diagram, components, upload instructions
```

## Contributing via Claude

1. Open an issue using the **Arduino Feature / Change** template
2. Fill in the board, wiring, and behavior details
3. Add the `claude` label when ready — Claude Code will implement it and open a PR
4. Review the PR carefully before uploading to hardware
